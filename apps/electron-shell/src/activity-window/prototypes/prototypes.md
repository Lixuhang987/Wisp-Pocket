# prototypes

本目录保存桌宠交互的一次性原型。评估布局、资料交付或对话状态时阅读；生产 renderer 的事实仍由 [activity-window.md](../activity-window.md) 维护。

## 直接子节点

- [pet-dialogue/pet-dialogue.md](./pet-dialogue/pet-dialogue.md)：多桌宠口袋对话、资料长桌、对话手册的 UI 比较，以及独立状态与原生实验入口。

原型仅由专用静态入口运行，不接入 ActivityWindow 的生产入口。保留可复核的场景与素材来源；生产实现需回到原模块和正式协议完成。
