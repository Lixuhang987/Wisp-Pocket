# Issue #3 设计讨论

本文记录 [前后端状态所有权收敛与中间层削减 #3](https://github.com/Lixuhang987/Wisp-Pocket/issues/3) 评估中已确认的修订约束。讨论尚未收敛，GitHub 正文尚未同步，本文不代表已批准实施。

## 已确认范围

- 本轮保持现有用户行为；自动重连、订阅恢复和待答请求补发另立需求，不作为既有能力或本轮验收项。
- 保留 [既有后端边界](./adr/0001-backend-state-ownership.md)：core 管理 Thread 业务与生命周期，agent-server 管理连接与协议适配。取消必须删除 Router 和 Persistence 的预设；移除代码前逐项确认职责及其归属。
- 全仓库 `types/`、`utils/` 标准化独立于本轮；本轮只整理涉及模块，避免无关路径迁移掩盖状态边界变化。

## 实施前提

- 以本地 `ad9336d` 中已提交的 Issue #2 实现作为本次评估基线。执行前确认目标分支包含该实现；读取最新代码与 owning 模块文档，不能按旧 GitHub 主分支套用文件与接口假设。
- 当前存储端口已存在；持久化适配承担输入转换、历史增量和恢复职责。接口定义或文件移动不等于新增依赖倒置，也不证明适配职责已经消失。

## 待决定

- 后端本轮有证据支持的精简项及停止边界。
- 验收所需的公开行为与时序，替代按删行数、文件数或测试数量判断完成。
