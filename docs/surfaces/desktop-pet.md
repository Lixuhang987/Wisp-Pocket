# 桌宠：轻量接续工作

- **模式**：Operate；角色是交互入口，其动画不将 surface 转为作品浏览模式。
- **范围**：桌面角色、资料拖入、当前气泡、建议与回复、悬停历史、大小控制；主入口 `apps/electron-shell/src/activity-window/App.tsx`。
- **用户与频率**：希望在当前桌面轻量交付资料和回复的用户；角色常驻，交互按需。
- **成功条件**：拖入目标明确，能理解接收与处理状态，继续当前任务，同时保留桌面其他区域的正常交互。

## 当前 surface 合约

- **THESIS**：角色接收资料，右侧对话承接当前任务；完整任务过程仍可从 ThreadWindow 访问。
- **OWN-WORLD**：保留月见八千代图集；气泡与控件继承共享主题，窗口空白区域透明并按命中区域穿透。
- **STORY**：拖到角色新建 → 读取并提出建议 → 点击建议或自由回复；拖到对话区则追加当前 Thread。
- **FIRST VIEWPORT**：启动仅显示角色；对话可见时角色位于左下，右侧从上到下为最新气泡、当前建议、回复框；悬停或输入焦点展开上方历史。角色右键可打开大小控件。
- **FORM**：现有透明桌面浮窗，采用角色/紧凑/展开三个布局状态；未选择替代方案，seed key 不适用。
- **FINISH**：现状与待实施方案已分开记录；本次未实测跨应用拖入、透明命中、屏幕边缘与焦点，不新增通过结论。

## 状态与约束

| 状态 | 当前行为 |
| --- | --- |
| 仅角色/主动隐藏 | 后台更新不主动解除隐藏；点击角色恢复气泡 |
| 拖入 | 角色提示新对话；对话区提示追加；松手时确定目标，再读取文件 |
| 接收/执行/待处理 | 显示相应状态；执行期间回复仍可提交并由后端排队 |
| 等待回复或授权 | 建议与自由输入继续任务；权限与工作区请求在展开对话中呈现 |
| 悬停或焦点 | 展开历史；历史与当前长正文分别滚动，当前建议可单独滚动 |
| 失败/连接变化 | 接收错误、任务错误与连接状态可呈现；桌宠有自己的重连恢复逻辑 |
| 调整角色 | 拖动位置、右键调整大小；对话字号和列宽不随角色同比缩放 |

当前选择按 Thread 创建时间确定，没有桌宠内手动切换入口；工具调用不进入桌宠历史。没有既有 Thread 时，即使点击显示气泡也不提供首次纯文字回复框。

## 当前与待实施的明确分界

当前关闭气泡使用关闭按钮，点击角色只恢复；展开条件包含悬停与输入焦点。最新正文和历史分别滚动。
