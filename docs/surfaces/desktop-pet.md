# 桌宠：轻量接续工作

- **模式**：Operate；角色是交互入口，其动画不将 surface 转为作品浏览模式。
- **范围**：桌面角色、首次文字、资料拖入、当前气泡、建议与回复、悬停统一浏览、本宠历史选择、伙伴管理与大小控制；主入口 `apps/electron-shell/src/activity-window/App.tsx`。
- **用户与频率**：希望在当前桌面轻量交付资料和回复的用户；角色常驻，交互按需。
- **成功条件**：点击后可直接输入，拖入目标明确，能理解接收与处理状态，继续当前任务，同时保留桌面其他区域的正常交互。

## 当前 surface 合约

**现有交互基线**：点击桌宠唤出并聚焦回复框，常态展示最新非空 assistant 消息及当前建议；仅 hover 对话区时展示当前 Thread 的全部用户 / assistant 历史消息，移出立即回到最新消息，输入焦点与草稿保持。再次点击隐藏整套对话，普通后台更新不解除主动隐藏；有效 Permission 请求召回隐藏宠及紧凑对话，不抢焦点或自动切 Thread。这里的“展开”专指悬停浏览，没有点击锁定或固定宽面板状态；每宠历史选择仅改变所选 Thread，继续遵守这条交互。

- **THESIS**：从角色点击或资料拖入开始，以固定回复框接续工作；完整任务过程仍可从 ThreadWindow 访问。
- **OWN-WORLD**：内置月见八千代保留图集，自定义角色使用受管静态图；气泡与控件继承共享主题，窗口空白区域透明并按命中区域穿透。
- **STORY**：点击角色唤出并聚焦 → 输入，首次发送才创建 Thread → 继续回复；也可拖到角色新建并交付路径，或拖到对话区追加。悬停查看完整内容，移出仍可输入，再次点击隐藏并保留草稿。
- **FIRST VIEWPORT**：启动仅显示角色；唤出后右侧对话列约 210px，底部约 44px 回复框为固定锚点，其上依次为全部当前建议和最新非空 assistant 气泡。无建议不占位，正文常态显示开头最多三行；无历史时可仅显示空回复框。右键角色打开控件，可调大小、选择对话、打开伙伴管理或隐藏角色。
- **FORM**：现有透明桌面浮窗，采用仅角色 / 紧凑对话 / 悬停展开三个布局状态；本次合入已实现的 Issue #5 方案，未进行新概念选择，seed key 不适用。
- **FINISH**：Issue #6/#7 在 Issue #5 合约上实现多宠、历史与路径输入；原实机证据只证明原构建，本次多宠 / 原生 / 真实模型仍待验。

## 状态与约束

| 状态 | 当前行为 |
| --- | --- |
| 启动仅角色 | 恢复可见宠集合和每宠选择；后台新 Thread 不切选或主动聚焦 |
| 主动隐藏 | 点击角色切换整套对话显隐，唤出时聚焦回复框；普通后台更新、错误和新 Thread 不解除主动隐藏，有效 Permission 请求例外 |
| 无历史/首条文字 | 打开空回复框不创建 Thread；首次发送等待匹配的持久接收确认，失败保留可编辑草稿，确认不擦掉期间新编辑的文字 |
| 拖入 | 角色提示新对话；对话区提示追加；松手时固定 petId / Thread 与稳定提交身份，再异步取得原路径；收到持久接收后才清输入 |
| 接收/执行/待处理 | 显示相应状态；执行期间回复仍可提交并由后端排队 |
| 等待回复或授权 | 建议与自由输入继续任务；权限请求在 hover 后呈现，标明宠与 Thread |
| 悬停 | 仅进入对话区展开；历史、完整最新正文、当前建议和交互请求共用一个滚动容器，回复框在其外；每次进入回到底部，同次上翻期间不抢回底部 |
| 移出/保持输入 | 立即回常态，保留回复框位置、焦点和草稿；自动聚焦本身不触发展开 |
| 内容溢出 | 常态和悬停均在上方容器边界裁剪；常态正文与建议不单独滚动，悬停通过统一容器查看完整内容 |
| 失败/连接变化 | 接收错误、任务错误与连接状态可呈现；桌宠有自己的重连恢复逻辑 |
| 调整角色 | 拖动位置、右键调整大小；对话字号和列宽不随角色同比缩放 |

每宠恢复上次有效主动选择，无选择时仅选本宠最近更新的历史。对话弹层支持本宠分页历史、新话题与确认删除；后台创建不抢选，删除后回本宠剩余历史或空态。草稿按宠与 Thread / new 持久化，点击显隐也按宠恢复，保存失败保留内存内容并提示。工具调用不进入桌宠历史。角色拖动结束不误触显隐切换；路径接收期间发生主动隐藏时，后续提交或错误不弹回对话。

## 实现与验收边界

每宠一个受控窗口，独立保存位置 / 大小，伙伴管理可搜索、创建、编辑、设为默认与召回。根目录只在创建时填写；名字 / 图片即时更新，旧 Thread 保留角色快照，并显示创建时的宠名与角色版本。窗口回收等待在途输入接收结束，隐藏不停止后端任务。

2026-09-15 合入 `f54d09f`，上述交互已实现，替代旧版关闭按钮、焦点保持展开、正文与历史分开滚动以及首次文字必须由 PromptPanel 发起的约束。

原功能分支已归档“常态紧凑布局”实机单项；悬停、首条输入和顶部裁剪另有部分原生验证记录。中文输入法、多屏/四角移动和真实透明穿透等完整待验项仍见 [manual-qa.md](../manual-qa.md)；原分支证据不等于本次合并产物已复验。
