# 桌宠：轻量接续工作

- **模式**：Operate；角色是交互入口，其动画不将 surface 转为作品浏览模式。
- **范围**：桌面角色、首次文字、资料拖入、当前气泡、建议与回复、悬停统一浏览、工作区历史选择、伙伴管理与大小控制；主入口 `apps/electron-shell/src/activity-window/App.tsx`。
- **用户与频率**：希望在当前桌面轻量交付资料和回复的用户；角色常驻，交互按需。
- **成功条件**：点击后可直接输入，拖入目标明确，完成回复可提醒查看，能继续当前任务，同时保留桌面其他区域的正常交互。

## 当前 surface 合约

**现有交互基线**：点击桌宠唤出并聚焦回复框，常态展示最新有可见内容的 assistant 消息及当前建议，只有建议时保留按钮而不创建空正文气泡；仅 hover 对话区时展示当前 Thread 的用户 / assistant 历史内容，空 / 空白助手正文不占气泡，移出立即回到最新消息，输入焦点与草稿保持。回复框聚焦时无矩形轮廓，光标和输入焦点保留，按钮键盘焦点提示与拖入高亮继续可见。再次点击隐藏整套对话，普通后台更新不解除主动隐藏；有效 Permission 请求召回隐藏宠及紧凑对话，不抢焦点，伙伴安排绑定请求所属 Thread。这里的“展开”专指悬停浏览，没有点击锁定或固定宽面板状态；选择工作区历史经唯一前端分配入口改变当前 Thread，继续遵守这条交互。

- **THESIS**：从角色点击或资料拖入开始，以固定回复框接续工作；完整任务过程仍可从 ThreadWindow 访问。
- **OWN-WORLD**：内置月见八千代保留图集，自定义角色使用受管静态图；气泡与控件继承共享主题，窗口空白区域透明并按命中区域穿透。
- **STORY**：点击角色唤出并聚焦 → 输入，首次发送才创建 Thread → 继续回复；也可拖到角色新建并交付路径，或拖到对话区追加。悬停查看完整内容，移出仍可输入，再次点击隐藏并保留草稿。
- **FIRST VIEWPORT**：首次无显隐偏好时仅显示角色，之后恢复逐宠对话显隐；角色周围不设常驻管理入口，伙伴、工作区对话、选择工作区、唤出新伙伴、隐藏和大小调节在角色右键菜单中提供，短 ID 在菜单中区分同名宠。唤出后右侧对话列约 210px，底部 composer 为固定锚点（44px 输入行、下方小图标工具行），其上呈现最新有可见内容的 assistant 项：有正文时显示气泡，当前建议独立显示，只有建议时不沿用旧正文；文件和新建对话在输入框下方，已选文件仅暂存为可移除的文件名 chip；运行时发送按钮切为停止。不显示身份标题气泡、根目录或路径提示。无建议不占位，正文常态显示开头最多三行；短内容 hover 前后保持底部位置。
- **FORM**：现有透明桌面浮窗，采用仅角色 / 紧凑对话 / 悬停展开三个布局状态；本次合入已实现的 Issue #5 方案，未进行新概念选择，seed key 不适用。
- **FINISH**：Issue #9 更新伙伴前端所有权、工作区接续与 Permission 承接，保留既有点击、hover、草稿与路径输入；原证据只证明原构建，当前完整宿主 / 真实模型待验。

## 状态与约束

| 状态 | 当前行为 |
| --- | --- |
| 启动恢复 | 恢复可见宠集合、每宠选择和对话显隐，首次无显隐偏好时仅显示角色；后台新 Thread 不切选或主动聚焦 |
| 主动隐藏 | 点击角色切换整套对话显隐，唤出时聚焦回复框；普通后台更新、错误和新 Thread 不解除主动隐藏，有效 Permission 请求例外 |
| 无历史/首条文字 | 打开空回复框不创建 Thread；首次发送等待匹配的持久接收确认，失败保留可编辑草稿，确认不擦掉期间新编辑的文字 |
| 拖入 | 角色提示新对话；对话区提示追加；松手时固定 petId / Thread 与稳定提交身份，再异步取得原路径；收到持久接收后才清输入 |
| 文件选择 | 仅暂存原路径，不开始 Turn；主动发送时以 `file_reference` 与文字统一提交，消息只显示文件名卡片，持久 ACK 后清理已提交资料，失败保留 |
| 接收/执行/待处理 | 不显示独立状态气泡；执行期间回复仍可提交并由后端排队，历史用户消息的 pending 与停止按钮保留 |
| 回复成功完成 | 当前 Thread 有正文或有效建议且成功完成后，角色右上角亮红点；查看对话或继续回复后清除，新一轮开始也清除，后台完成不揭示对话或抢焦点 |
| 等待回复或授权 | 建议与自由输入继续任务；任意来源有效 Permission 复用或召来伙伴并关联正确工作区 / Thread，非激活呈现；无库存只提示等待授权且需要新建伙伴 |
| 悬停 | 仅进入对话区展开；历史、完整最新正文、当前建议和交互请求共用一个滚动容器，回复框在其外；每次进入回到底部，同次上翻期间不抢回底部 |
| 移出/保持输入 | 立即回常态，保留回复框位置、焦点和草稿；自动聚焦本身不触发展开 |
| 内容溢出 | 常态和悬停均在上方容器边界裁剪；常态正文与建议不单独滚动，悬停通过统一容器查看完整内容 |
| Markdown 正文 | 助手支持 Markdown / GFM；用户正文从结构化文字项提取并保留原文（包括主动输入的路径），文件引用只显示文件名卡片；常态约三行高度预览、hover 全文，代码和表格折行，任务复选框只读。原始 HTML 与 Markdown 图片显示文字；仅绝对 HTTP/HTTPS 链接可点击并交给系统浏览器 |
| 失败/连接变化 | 接收与任务错误继续呈现；不显示独立连接状态气泡，桌宠仍有自己的重连恢复逻辑 |
| 调整角色 | 拖动位置、右键菜单选择“调整大小”；对话字号和列宽不随角色同比缩放 |

每宠从 Electron main store 恢复当前 Workspace / Thread，空选择保持新话题；历史弹层按工作区分页并支持确认删除，失效引用清空当前关联，普通读取故障不当作删除。新建话题先清关联，首次发送才创建；后台创建不抢选。文字与待发路径仍按宠与 Thread / new 保存，草稿转移不在本期另设规则。角色拖动结束不误触显隐；接收期间主动隐藏，后续确认或错误不弹回。

红点是本宠 renderer 的未查看提示：只有观察到成功完成才记录，流式、持久 ACK、Permission、纯工具轮、失败和中断不点亮。已记录标记随重建恢复，但普通历史 snapshot 不补推断断线期间的新完成；已读不跨前端同步。具体状态所有权见 [模块约定](../../apps/electron-shell/src/activity-window/activity-window.md)。

## 实现与验收边界

每宠一个受控窗口；资料、图片、Workspace / 当前 Thread、显隐、位置和大小由 Electron main 唯一 Pet store 持久化，表单与宠窗经 IPC 操作。桌宠内紧凑伙伴管理与右键仍按工作区 / 历史两级选择后分配：明确选伙伴可接管隐藏关联，可见伙伴占用不可夺取；自动开历史或 Permission 复用已有伙伴，否则用隐藏库存。设置卡片改为直接系统选目录，同项目保留当前 Thread、换项目准备新话题，见 [设置 surface](./settings.md)。首轮角色作为普通输入添加一次，旧历史不重新注入；消息中以独立单行角色附件展示，超宽省略、悬停 title 查看全文，正文只保留原输入；首轮摘要按 opId 在持久确认 / Turn / 正式历史之间收敛，恢复不会再次补出待处理气泡；隐藏、换项目和清空选择不停止后端任务，回收窗口等待在途接收结束。目录失效保留安排并阻止新 Turn，不自动换项目。

2026-09-15 合入 `f54d09f` 的点击输入、常态收紧与悬停统一滚动是交互基线，替代旧版关闭按钮、焦点保持展开、正文与历史分开滚动以及首次文字必须由 PromptPanel 发起的约束。2026-10-03 用户修订为仅右键菜单提供管理入口、当前对话不展示目录，输入与工具行固定，消息统一底部对齐；右键与悬停回归、本轮输入工具行各自的验证范围见 [manual QA](../manual-qa.md)。

原功能分支已归档“常态紧凑布局”实机单项；悬停、首条输入和顶部裁剪另有部分原生验证记录。中文输入法、多屏/四角移动和真实透明穿透等完整待验项仍见 [manual-qa.md](../manual-qa.md)；原分支证据不等于本次合并产物已复验。
