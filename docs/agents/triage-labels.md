# Triage 标签

工程 skills 使用五个固定角色。下表定义角色对应的 GitHub label：

| Skill 角色 | GitHub label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交给无人值守 agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 决定不处理 |

当 skill 使用角色语义时，必须采用本表对应的 label。若仓库以后更换标签词汇，只修改 GitHub label 列。
