# 权限只记忆工具级永久决定

已接受并已实现，原需求纳入 [实施规格 #2](https://github.com/Lixuhang987/Wisp-Pocket/issues/2)。当前协议、Runtime、共享权限存储与 Settings 均采用本次 / 永久范围；ThreadWindow 与桌宠均提供本次 / 永久决定入口；永久范围明确对所有桌宠的该工具生效。

权限决定只保留本次与永久两种记忆范围，删除当前 Thread 范围及其内存规则。永久决定按工具名称匹配，不比较调用参数；允许和拒绝均遵守这一规则，并跨 Thread、跨后端重启生效。

这一选择使同一工具使用不同参数时沿用永久决定，取代原来的工具名称与参数共同匹配。Thread 不再拥有授权记忆，只拥有尚未完成的交互请求；永久权限由后端共享的权限存储拥有。

后续修改须同步权限协议、运行逻辑、审批选项、设置中的规则展示与撤销，以及相关测试；不能只改后端匹配而留下旧的 Thread 授权入口。多宠不会把全局永久决定改为每宠权限，规格边界见 [spec 索引](../medium-powers/specs/specs.md)。
