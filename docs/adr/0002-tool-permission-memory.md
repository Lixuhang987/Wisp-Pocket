# 权限只记忆工具级永久决定

已纳入 [实施规格 #2](https://github.com/Lixuhang987/Wisp-Pocket/issues/2) 并实现。当前权限策略、Runtime、协议与 Settings 均使用下述范围；ThreadWindow 提供永久决定入口，桌宠界面目前仅呈现本次允许与拒绝，不能把协议支持等同于全部界面已经提供选项。

权限决定只保留本次与永久两种记忆范围，删除当前 Thread 范围及其内存规则。永久决定按工具名称匹配，不比较调用参数；允许和拒绝均遵守这一规则，并跨 Thread、跨后端重启生效。

这一选择使同一工具使用不同参数时沿用永久决定，取代原来的工具名称与参数共同匹配。Thread 不再拥有授权记忆，只拥有尚未完成的交互请求；永久权限由后端共享的权限存储拥有。

后续调整权限记忆范围时，须同步权限协议、运行逻辑、界面选项、设置中的规则展示与撤销，以及相关测试，保持所有入口对范围的解释一致。
