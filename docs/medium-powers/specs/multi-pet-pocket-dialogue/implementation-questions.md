## 工程补齐边界

- 隐藏只改展示：在途提交不能因 renderer 销毁丢失；提交确认期间延后回收。已确认输入继续运行，未确认失败保留对应草稿 / 路径与稳定身份。
- 隐藏宠被回收后也必须收到有效 Permission 的展示意图；后台连接仅消费后端事实以召回窗口，不在 Electron main 复制请求或历史 owner。同宠其他 Thread 不加聚合提醒或自动导航。
- 同文件锁按真实目标路径串行；等待锁的调用在真正写入前检查 Turn 中断，已完成的磁盘写入不能声称回滚。
- 多窗各自用绑定 petId 的配置、布局和草稿键；新宠默认显示，重启恢复可见集合，隐藏后有管理入口召回。Permission 是主动隐藏的明确例外。
- Thread 创建与首轮提交分步失败时保留同一个空 Thread 和提交身份，重试不能再创建一段历史；角色提示通过后端 system section 注入。
