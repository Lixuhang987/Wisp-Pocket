# 桌宠悬停浮动气泡调整

## 用户确认的目标

2026-09-13 用户要求：收起时保留现有最新 assistant 气泡；悬停时主气泡的位置不变，历史在其上方以多个独立气泡出现，去掉覆盖整个历史的背景，形成角色头顶浮着对话的形态。

## 本次用例

1. 当前 Thread 已有用户消息和 assistant 回复，收起时只显示最新 assistant 内容。
2. 鼠标进入主气泡：同一个主气泡保持原位，上方出现受限高度的透明历史区，桌宠消息在左、用户消息在右，每条有自己的气泡。
3. 当前主气泡不在历史中重复；悬停后可在其固定正文区域滚动读完长回复。建议作为独立操作气泡显示，Permission/Workspace 继续使用各自控件。
4. 回复框作为独立小气泡位于角色左侧的空白处；输入焦点仍保持展开，离开且失焦后收起。
5. 历史过长时滚动；查看旧内容期间新消息不抢滚动位置。透明间隙允许点击下方应用，实际气泡、回复框和角色保持命中及拖入能力。
6. 靠近屏幕上缘时压缩历史可用高度；悬停不改变已经可见的主气泡或角色的屏幕位置。

## 实现边界

- `App` 的鼠标/焦点状态选择 `pet/compact/expanded`；收起与展开保留同一主气泡节点，历史和回复框由独立表面承载，外层保持透明。
- `PetConversation` 消费现有 `ThreadState.messages`、Permission/Workspace 请求，处理历史滚动、建议与普通回复。
- `PetThreadController` 与既有 store 继续提供当前 Thread 和最新 assistant；本次不新增会话状态或数据协议。
- `handAgentPet.setLayout` 仍只接收三个既有模式；`setInteractiveRegions` 仍接收 viewport 本地矩形数组。renderer 逐个上报可见气泡，历史矩形与滚动视口取交集，并在滚动和尺寸变化后刷新。
- 原生 `ActivityWindowController` 继续拥有角色右下角锚点；`expanded` 的高度额外受该锚点到工作区顶部的距离限制，不能借展开移动锚点。
